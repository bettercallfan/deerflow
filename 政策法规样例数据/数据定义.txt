8. metadata 子字段说明
=============================================================
metadata 字典包含完整的法律层级信息，主要子字段：

  层级信息：
    ├── part_label / part_title        # 编级信息
    ├── part_number                    # 编数字编号
    ├── subpart_label / subpart_title  # 分编信息
    ├── subpart_number                 # 分编数字编号
    ├── chapter_label / chapter_title  # 章级信息
    ├── chapter_number                 # 章数字编号
    ├── section_label / section_title  # 节级信息
    └── section_number                 # 节数字编号

  基础信息：
    ├── title                          # 法律标题
    ├── type                           # 类型
    ├── status                         # 状态
    ├── office                         # 发布机关
    ├── office_level                   # 机关层级
    ├── office_category                # 机关类别
    ├── publish_date                   # 发布日期
    ├── effective_date                 # 生效日期
    └── effective_period               # 生效时间段
