# document-parse 文档解析系统分析

## 一、项目概述

一个基于 PaddleOCR-VL 的智能文档解析系统，支持图片和 PDF 的 OCR 识别、结构化提取和 Markdown 输出。带自适应预处理流水线和 Vue 3 前端。

**核心技术栈**：
- **OCR 引擎**：PaddleOCR-VL（`paddleocr`），PP-DocLayoutV3 版面检测 + PaddleOCR-VL-1.5 识别
- **后端**：FastAPI（端口 8000）
- **前端**：Vue 3 + Vite（端口 5173）
- **预处理**：OpenCV 自适应图像增强

## 三、后端架构 (`app.py`)

### 3.1 API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/health` | 健康检查 |
| `POST` | `/api/parse` | **核心**：上传文件 → 预处理（可选）→ OCR → 返回 Markdown |
| `GET` | `/api/result-file/{job_id}/{section}/{filename}` | 获取预处理后的图片或解析结果文件 |
| `GET` | `/api/download-md/{job_id}` | 下载 Markdown 文件 |

### 3.2 解析流程

```
POST /api/parse (file + preprocess: bool)
  │
  ├─ 1. 文件上传 → uploads/{job_id}/原始文件
  │
  ├─ 2. 预处理（仅图片，preprocess=true）
  │     └─ AdaptiveDocumentPreprocessor.process_file()
  │         ├─ 特征提取（模糊度、亮度、倾斜角、表格密度等）
  │         ├─ 自适应路由（根据特征决定处理链）
  │         ├─ 执行处理链（去阴影、校正、锐化、增强等）
  │         └─ 输出：preprocess/图片_processed.png + route_report.json
  │
  ├─ 3. PaddleOCR-VL 解析
  │     └─ PaddleOCRVL.predict(input)
  │         → restructure_pages()（合并表格、标题层级、拼接页面）
  │         → save_to_markdown()
  │         → 输出：parse/xxx.md
  │
  └─ 4. 返回 JSON
        {
          jobId, filename, isImage, preprocessed,
          processedImageUrl, markdown, markdownDownloadUrl,
          preprocessReport, warnings
        }
```

## 四、预处理模块 (`adaptive_preprocess.py`)

### 4.1 概述

`AdaptiveDocumentPreprocessor` 是一个**自适应图像预处理流水线**，根据输入图片的特征自动选择最优的处理链。对模糊、倾斜、阴影、低对比度等常见文档扫描问题进行针对性增强，提高下游 OCR 准确率。

### 4.2 特征提取

提取 10 个维度的图像特征：

| 特征 | 计算方法 | 阈值 |
|------|---------|------|
| `blur_score` | Laplacian 方差 | < 80 → 模糊 |
| `brightness` | 灰度均值 | < 90 → 偏暗 |
| `contrast` | 灰度标准差 | < 45 → 低对比度 |
| `skew_angle` | 基于文本框的倾斜角估计 | > 4° → 倾斜 |
| `edge_density` | Canny 边缘密度 | > 0.10 → 文字密集 |
| `table_score` | 横向+纵向线检测 | > 0.06 → 可能是表格 |
| `shadow_score` | 大尺度背景模糊的标准差 | > 35 → 有阴影 |
| `small_image` | 宽+高 < 1600 | 小图要放大 |

### 4.3 自适应路由规则

根据特征组合自动选择处理链：

```
必定执行: to_gray

if 有阴影:
    remove_shadow → recheck_deskew
elif 倾斜:
    deskew

if 偏暗:    gamma_correct
if 低对比度: clahe + sharpen
if 模糊:    sharpen
if 表格:    table_line_enhance + light_denoise
if 小图:    upscale(x2)

最终: sharpen
```

### 4.4 算子清单

| 算子 | 功能 | 核心API |
|------|------|--------|
| `to_gray` | 彩色转灰度 | `cv2.cvtColor(BGR2GRAY)` |
| `deskew` | 倾斜校正 | `cv2.getRotationMatrix2D + warpAffine` |
| `remove_shadow` | 阴影去除 | 大尺度高斯模糊背景估计 + 除法归一化 |
| `gamma_correct` | Gamma 校正（提亮暗部） | LUT 查表 |
| `clahe` | 自适应直方图均衡 | `cv2.createCLAHE` |
| `sharpen` | USM 锐化 | `cv2.addWeighted` |
| `light_denoise` | 轻量去噪 | `cv2.medianBlur` |
| `table_line_enhance` | 表格线增强 | 形态学提取横线竖线 + 叠回原图 |
| `upscale` | 2倍放大 | `cv2.resize(INTER_CUBIC)` |
| `denoise` | Non-Local Means 去噪 | `cv2.fastNlMeansDenoising` |

### 4.5 倾斜角估计

用**基于文本框**的方法（`estimate_skew_angle_by_text_boxes`）替代传统的全图 minAreaRect：

1. 二值化（OTSU）
2. 横向膨胀连接字符成行
3. 提取文本框（过滤噪声小块和超大块）
4. 每个文本框单独计算 minAreaRect 角度
5. 取中位数（抗异常值）

比全图法更稳定，不受页面边缘干扰。

## 五、OCR 引擎 (PaddleOCR-VL)

### 5.1 模型链

```
输入图片
  ↓
PP-DocLayoutV3（版面检测）→ 识别标题、正文、表格、图片区域
  ↓
PaddleOCR-VL-1.5-hw（视觉语言识别）→ 文字提取 + 结构理解
  ↓
restructure_pages() → 合并表格、调整标题层级、拼接多页
  ↓
save_to_markdown() → Markdown 输出
```

### 5.2 输出格式

- **Markdown**（`.md`）：包含标题层级、表格、图片引用
- **图片提取**：自动识别并裁剪文档中的嵌入图片，保存到 `imgs/` 子目录
- **JSON**（可选，`_res.json`）：结构化结果

### 5.3 支持的文件类型

| 类型 | 扩展名 | 预处理 |
|------|--------|--------|
| 图片 | `.png`, `.jpg`, `.jpeg`, `.bmp`, `.tif`, `.tiff` | ✅ |
| PDF | `.pdf` | ❌（预留接口） |

## 八、可复用模块

以下模块可以直接或稍作修改后集成到 Crawler Agent 中：

### 8.1 自适应预处理

`adaptive_preprocess.py` 的 `AdaptiveDocumentPreprocessor` 可以作为 Crawler Agent 的图片预处理步骤。当爬虫下载到图片后，先过一遍预处理增强 OCR 效果：

```python
from pre.adaptive_preprocess import AdaptiveDocumentPreprocessor

preprocessor = AdaptiveDocumentPreprocessor(debug=False)
report = preprocessor.process_file(downloaded_image, output_dir)
enhanced_image = report["output_file"]  # → 喂给 OCR
```

### 8.2 PaddleOCR-VL 替换 Qwen-VL-OCR

当前 Crawler Agent 的 OCR 用的是 `qwen-vl-ocr` @ WCODE API（远程调用）。可以替换为本地的 PaddleOCR-VL：

```python
from paddleocr import PaddleOCRVL
pipeline = PaddleOCRVL(
    layout_detection_model_dir="/path/to/PP-DocLayoutV3",
    vl_rec_model_dir="/path/to/PaddleOCR-VL-1.5-hw",
)
output = pipeline.predict(input=image_path)
for res in output:
    res.save_to_markdown(save_path=output_dir)
```

优势：本地推理（无需 API Key）、手写中文识别更强、版面分析更准。

### 8.3 文件上传 + 解析 API

`app.py` 的文件上传 → 预处理 → OCR → Markdown 流程可以直接作为 Crawler Backend 的一个新端点，支持用户上传扫描文档进行解析。
