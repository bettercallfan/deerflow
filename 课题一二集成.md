# 课题一二集成：Crawler Agent 集成到 DeerFlow 数据中心

## 一、项目背景

### 原系统：Crawler Agent

一个独立的智能爬虫系统，位于 `crawl_agent/` 目录下：

```
crawl_agent/
├── crawler_agent_backend/        # FastAPI 后端 (端口 8000)
│   ├── app/
│   │   ├── main.py               # FastAPI 应用入口
│   │   ├── api/v1/               # REST API (tasks, schedules, model-configs, storage)
│   │   ├── services/             # 业务逻辑层 (crawl_service, schedule_service 等)
│   │   ├── models/               # SQLAlchemy 数据模型 (CrawlTask, CrawlPage, CrawlResult 等)
│   │   └── legacy_bridge/        # 桥接层 — 调用爬虫引擎
│   ├── crawler_agent/            # 爬虫核心引擎
│   │   ├── crawler_entrance.py   # 主入口：browse_page() 浏览器导航
│   │   ├── browser_use_agent/    # BrowserAgent (ReAct Agent + Playwright MCP)
│   │   ├── web_info_extract/     # LLM 结构化信息提取
│   │   └── html_to_markdown/     # ReaderLM HTML→Markdown 转换
│   └── run.py                    # uvicorn 启动
└── crawler_agent_fronted/        # Vue 3 前端 (废弃，不再使用)
```

**原系统核心技术栈**：
- 浏览器自动化：Playwright + Chromium，通过 `npx @playwright/mcp@latest` 暴露 MCP 工具
- AI 导航：AgentScope ReAct Agent 驱动浏览器自主导航和翻页
- 内容提取：支持 HTML / Markdown (ReaderLM + Qwen-VL OCR) / JSON (HTMLRecursiveExtractor) 三种输出模式
- 元数据管理：SQLite 存储任务、运行记录、页面、结果

### 目标系统：DeerFlow

一个 LangGraph 驱动的 AI 超级智能体系统，包含完整的前后端架构：

```
imiss-deer-flow/
├── backend/                       # Python 后端
│   ├── app/gateway/               # FastAPI Gateway (端口 3218)
│   │   ├── app.py                 # FastAPI 应用 + 路由注册
│   │   └── routers/               # 各业务路由模块
│   └── packages/harness/deerflow/ # Agent 核心框架
├── frontend/                      # Next.js 16 前端
│   └── src/
│       ├── app/workspace/data-center/  # 🎯 数据中心页面
│       ├── components/workspace/data-center/  # 数据中心组件
│       └── core/                  # 业务逻辑层
├── docker/                        # Docker 部署配置
│   ├── docker-compose.yaml        # 生产环境
│   ├── docker-compose-dev.yaml    # 开发环境
│   └── nginx/                     # Nginx 反向代理配置
```

### 关键设计决策

| 决策 | 说明 |
|------|------|
| **不采用 iframe** | 不嵌入原 Vue 前端，在 DeerFlow 中原生实现 React 组件 |
| **不修改 Crawler Backend 代码** | DeerFlow Gateway 通过 HTTP 代理方式调用 Crawler API，保持 Crawler 独立性 |
| **容器化部署** | Crawler Backend 作为独立 Docker 服务运行，与 DeerFlow 共享 docker 网络 |
| **第一阶段最小闭环** | 只实现：创建任务 → 执行爬取 → 展示结果。不接 ES/RAG/数据源导入 |

## 四、后端实现详解

### 4.1 Gateway Crawler 路由

**文件**：`backend/app/gateway/routers/crawler.py`

该路由是 DeerFlow Gateway 与 Crawler Backend 之间的桥梁，通过 HTTP 代理方式将前端请求转发到 Crawler Backend。

```python
# 关键常量
CrawlerBackendURL = os.getenv("CRAWLER_BACKEND_URL", "http://127.0.0.1:8000").rstrip("/")
```

**API 端点**：

| 方法 | 路径 | 说明 | 内部转发 |
|------|------|------|----------|
| `POST` | `/api/data-center/crawler/tasks` | 创建爬取任务 | `POST {crawler}/api/v1/crawl/tasks` |
| `GET` | `/api/data-center/crawler/tasks` | 任务列表（支持分页+状态过滤） | `GET {crawler}/api/v1/crawl/tasks` |
| `GET` | `/api/data-center/crawler/tasks/{id}` | 任务详情（含运行状态） | `GET {crawler}/api/v1/crawl/tasks/{id}` |
| `GET` | `/api/data-center/crawler/tasks/{id}/results` | 爬取结果 | `GET {crawler}/api/v1/crawl/tasks/{id}/results` |

**请求/响应数据模型**（Pydantic）：

```python
class CrawlTaskCreateRequest(BaseModel):
    name: str           # 任务名称
    portal_url: str     # 目标网址
    query: str          # 爬取内容描述
    output_mode: Literal["html", "markdown", "json"]  # 输出格式

class CrawlTaskItem(BaseModel):
    id, name, portal_url, query, output_mode, status, progress,
    source, skip_reason, error_message, result_summary,
    created_at, started_at, finished_at

class CrawlResultItem(BaseModel):
    page_id, url, title, is_duplicate, duplicate_reason,
    raw_html_hash, normalized_content_hash,
    result_type, result_json, result_markdown, result_markdown_ocr
```

### 4.2 Gateway 路由注册

**文件**：`backend/app/gateway/app.py`

改动内容：
1. 导入 `crawler` 模块
2. 注册路由：`app.include_router(crawler.router)`（路径前缀已在 router 内定义）
3. 新增 OpenAPI tag：`{"name": "crawler", "description": "Web crawling task management — create, monitor, and retrieve results from the crawler agent"}`

### 5.2 UI 组件

所有组件均遵循 DeerFlow 现有数据中心视觉风格（圆角卡片、统一的间距/配色）。

## 六、Docker 容器化

### 6.1 Crawler Backend Dockerfile

**文件**：`crawl_agent/crawler_agent_backend/Dockerfile`

```dockerfile
FROM python:3.12-slim

# 1. 安装系统依赖
#    - Node.js 22 (Playwright MCP 需要 npx)
#    - Chromium 运行时库 (libnss3, libatk-bridge, libcups2 ...)
RUN apt-get install -y nodejs + 各种 Chromium 依赖

# 2. 安装 Python 依赖
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 3. 预装 Playwright Chromium 浏览器
RUN npx --yes playwright install chromium

# 4. 复制应用代码
COPY . .

EXPOSE 8000
CMD ["python", "run.py"]
```

### 7.2 配置 Crawler LLM 模型（必须！）

Crawler Backend 启动后**没有默认模型**，必须通过 API 配置，否则爬取任务会失败。

```bash
# 配置导航模型（BrowserAgent 使用）
curl -X PUT http://localhost:8000/api/v1/model-configs/crawler_agent \
  -H "Content-Type: application/json" \
  -d '{
    "api_key": "你的API_KEY",
    "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "model_name": "qwen-plus"
  }'

# （可选）配置 JSON 提取模型
curl -X PUT http://localhost:8000/api/v1/model-configs/recursive_acquisition \
  -H "Content-Type: application/json" \
  -d '{
    "api_key": "你的API_KEY",
    "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "model_name": "qwen-plus"
  }'
```

验证配置：
```bash
curl http://localhost:8000/api/v1/model-configs | python -m json.tool
# 应看到 crawler_agent 和 recursive_acquisition 的 is_configured: true
```

```
│                                                                     │

│         └── crawl_result    (提取结果)                              │
```
