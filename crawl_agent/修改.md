
- 默认关闭截图（纯文本模式）
- 设置环境变量 `ENABLE_SCREENSHOTS=1` 可开启（需要视觉模型）

### 8.3 原因

OpenRouter 中国区没有同时支持视觉+工具调用的模型：

| 模型 | 视觉 | 工具调用 |
|------|------|----------|
| `qwen/qwen3-32b` | ❌ | ✅ |
| `qwen/qwen2.5-vl-72b-instruct` | ✅ | ❌ |
| `deepseek/deepseek-chat` | ❌ | ✅ |

纯文本模式下 DOM 快照已包含所有可见文字和元素 ref，导航够用。

## 九、HTML 兜底抓取

**文件**: `crawler_agent_backend/crawler_agent/crawler_entrance.py`

Agent 结束时如果只返回了 `<url>` 文本而没有调用 `save_url` 工具，直接用 `browser_evaluate` 提取当前页面的完整 HTML：

```python
payload = await _browser_evaluate_json(
    """() => ({
        url: window.location.href || "",
        title: document.title || "",
        html: document.documentElement ? document.documentElement.outerHTML : ""
    })"""
)
if payload.get("html"):
    _store_page_record(
        url=payload.get("url", urls[0]),
        title=payload.get("title", ""),
        html=payload["html"],
        capture_method="fallback_on_exit",
    )
```
